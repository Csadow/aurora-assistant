Memory and backups

Notes contain Markdown and [[links]]. They are stored in this app’s private database. Export them as ordinary .md files to use in Obsidian.

Imports never overwrite a different note: both versions are kept. Backups contain private text, but no API key. Keep a copy before uninstalling or clearing app data.
